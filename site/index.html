Everything your vault needs

Real KeePass files
Full KDBX4 read and write, so your vault keeps working with KeePassXC and other KeePass apps.
Your storage
Open a vault from disk where your browser allows it, or keep it in your own Google Drive.
Autofill
Detects login forms, including multi-step sign-ins, and fills only on sites you have trusted.
Passwords and passphrases
Generate either one, then let Keetar spot when you use it to change a saved login.
Password health
Finds weak, reused, old and breached passwords. Breach checks send only a short hash prefix to Have I Been Pwned.
One-time codes
Generate and fill TOTP codes for entries with a stored secret.
Passkeys
Optionally create and sign in with passkeys on websites.
Hardware key and biometric unlock
Unlock with a FIDO2 security key, Touch ID or Windows Hello through WebAuthn PRF. Firefox needs version 150 or later.
Bring your data
Import from CSV, Bitwarden, 1Password and Proton Pass, or combine a second vault into your current one.

There is no Keetar server

Your vault is encrypted with the same KDBX4 format KeePassXC uses, and your master password never leaves your device. There's no telemetry and nothing to sign up for.

Read exactly what goes where

  • On your deviceYour master password and decrypted vault
  • In your storageThe encrypted vault file, on disk or in your Google Drive
  • On a Keetar serverNothing, because there isn't one

Install

Get Keetar for Chrome Get Keetar for Firefox

Keetar isn't in the Chrome Web Store or Firefox Add-ons yet, so these links go to GitHub for now. Until then, you can build it from source with Node 24+ and pnpm:

git clone https://github.com/papacodebear/keetar.git
cd keetar
pnpm install
pnpm run build
  • Chrome: open chrome://extensions, turn on Developer mode, choose Load unpacked, and select packages/web/dist/chrome.
  • Firefox: open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select any file in packages/web/dist/firefox.
